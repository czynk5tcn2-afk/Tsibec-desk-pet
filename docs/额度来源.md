# 额度来源：给桌宠接一个新的 AI 工具

> 这份文档是写给 AI 助手看的（Claude、Codex、豆包、Kimi、DeepSeek……都行）。
> 用户只要把这份文档发给自己的 AI，说一句“帮我把 XX 的额度接到桌宠上”，AI 照着做就行。
> **不需要改桌宠的代码，也不需要重新编译。**

## 一句话原理

桌宠每 20 秒看一次文件夹 `~/.pet-quota/`，把里面每个 `.json` 文件当成一个额度来源。
谁往这里写一个符合格式的文件，桌宠就会显示它；数字变了就冒气泡提醒。

## 文件格式

路径：`~/.pet-quota/<随便起个英文文件名>.json`（以 `.` 开头的文件会被忽略，可以拿来放临时文件）

```json
{
  "name": "豆包",
  "updated_at": 1791550000,
  "windows": [
    { "label": "每天", "used_percent": 42,   "resets_at": 1791600000 },
    { "label": "每周", "used_percent": 18.5, "resets_at": 1792000000 }
  ]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 建议填 | 显示名字。不填就用文件名。叫 `Claude` 的文件会被当成 Claude 的官方数据，优先使用 |
| `updated_at` | 建议填 | 这份数据是什么时候拿到的，Unix 时间戳（秒） |
| `windows` | 必填 | 一个或多个额度窗口 |
| `windows[].label` | 必填 | 窗口名字，比如 `5 小时`、`每天`、`每周`、`本月`。写 `每周` 会显示成“这周” |
| `windows[].used_percent` | 必填 | **已经用掉**的百分比，0~100，可以带小数。如果工具给的是“剩余”，用 100 减一下 |
| `windows[].resets_at` | 可选 | 什么时候重置，Unix 时间戳（秒）。过了这个时间桌宠会显示“已重置” |

写文件时请**先写临时文件再改名**（`xxx.json.tmp` → `xxx.json`，或者 `.xxx.tmp`），免得桌宠读到写了一半的文件。

## 怎么拿到额度数字（按好做程度排）

1. **工具自己在本机留了记录**（最好）：很多命令行 AI 工具会在用户目录下写日志或缓存，里面常常带着用量。找到以后写个小脚本，定时（或每次用完）把数字转写成上面的格式。
   - 例子：Codex 把额度写在 `~/.codex/sessions/年/月/日/rollout-*.jsonl` 的 `token_count` 事件里（`rate_limits.primary` 是 5 小时、`secondary` 是每周）。桌宠已经内置了 Codex，不用再写。
2. **工具提供了状态栏 / 钩子 / 插件接口**：在接口里顺手把额度写进文件。
   - 例子：本仓库 `extras/claude-statusline.sh`。Claude Code 每次刷新状态栏时会把 `rate_limits.five_hour` / `seven_day` 传给脚本，脚本写成 `~/.pet-quota/claude.json`。用法：在 `~/.claude/settings.json` 里加
     `"statusLine": {"type": "command", "command": "/完整路径/extras/claude-statusline.sh"}`。
     只有 Pro / Max 订阅才有这些数字，并且要新开一个会话、回答过一次以后才有。
3. **工具有官方的用量查询接口（API）**：写个脚本定时查询，再写成文件。用官方公开的接口和用户自己的 API Key。
4. **只有网页上能看到**：可以用浏览器插件（油猴脚本）在用户打开那个网页时读出数字，再想办法存成文件。这种最脆弱，网页一改版就失效。

**不要做的事**：不要去读、复制或上传用户的登录凭证（token、cookie、密码），不要调用没公开的内部接口去刷数据。这些既不安全，也可能违反服务条款。拿不到干净的数据时，告诉用户“这个工具暂时接不了”就好。

## 定时运行脚本（macOS）

如果数字只能靠脚本主动去取，可以用 `launchd` 每几分钟运行一次：在 `~/Library/LaunchAgents/` 放一个 plist，`StartInterval` 设成 300（秒），`ProgramArguments` 指向脚本。改完用 `launchctl load` 加载。别设太频繁，几分钟一次足够。

## 怎么确认接好了

1. 打开文件夹：桌宠右键菜单 → 额度来源 → 打开额度文件夹，看文件在不在、内容对不对（可以用 `python3 -m json.tool 文件名` 检查格式）。
2. 右键菜单 → 看看额度：应该多出一行，比如 `豆包　每天 42%　这周 18.5%`。
3. 手动改一下 `used_percent` 再保存，20 秒内她会冒“额度变化”的气泡。
4. 不想看某个来源：右键菜单 → 额度来源，把它的勾去掉（文件不用删）。

## 桌宠这边对应的代码（一般不用动）

`Sources/main.swift` 里的 `FolderWatcher`：读文件夹、比较前后两次、发现变化后交给 `quotaChanged` 冒泡；`showQuota` 负责“看看额度”的显示。
